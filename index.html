NovaMart

Full-Stack E-Commerce Platform

A full-stack e-commerce web application designed to provide a complete online shopping experience. It features a modern, responsive user interface and a structured backend API, supporting essential e-commerce operations through a full-stack architecture.

Problem

Many users struggle with e-commerce websites: confusing interfaces, complicated shopping processes and usability issues that hurt the shopping experience. I wanted to understand these problems and build a platform with a smoother, more user-friendly experience.

Solution

I analyzed common usability and navigation problems users face on e-commerce sites. Based on those observations, I designed and developed NovaMart around a modern interface, organized shopping features and a structured full-stack architecture, building both the frontend and the backend on my own.

Result

NovaMart was completed as a full-stack e-commerce application that matched my original expectations and objectives. It let me apply frontend development, backend API development, database management, authentication and software architecture.

Built with

Frontend: React 18, Vite 5, TypeScript, Tailwind CSS, Plus Jakarta Sans, Lucide. State: Redux Toolkit.

Backend: Node.js 20, Express.js, TypeScript, REST API, Clean Architecture. Database: MongoDB, Mongoose ODM.

Auth & validation: JWT, refresh tokens, HTTP-only cookies, Zod. Logging & infrastructure: Winston, Morgan, Docker, Docker Compose, Nginx. Testing: Jest, Supertest.

Developed independently: frontend, backend API, database design, authentication, state management, validation, logging, testing and architecture.
